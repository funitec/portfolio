現在の研究

拡散モデルによるロボットモーション生成

Transformer を用いたロボットのモーション生成を研究。拡散モデルをコアに据えた モーション生成フレームワークを構築し、ロボットが意図を非言語的に伝える 動作表現の実現を目指しています。学会発表を準備中。

Sim-to-Real

Unitree Go2 の強化学習と実機展開

Isaac Sim・Genesis を用いた強化学習環境で Unitree Go2 の方策を学習し、 sim-to-real による各関節モーター制御の実機接続・実装まで完遂。 ドメインランダマイゼーションの設計とリワード関数のチューニングが sim-to-real の成否を左右することを実践から習得しました。 オリジナル設計の倒立振子ロボットでの強化学習も実施。

Works

制作物

個人開発・論文再現実装など。AIとインタラクション、モーション技術の実験場。

Emotion Avatar

キャラクターAI ／ Unity + Python

「関係性を築けるキャラクター」を目指した感情アバターアプリ。Russell感情円環と Ekman 6基本感情、信頼・親密度を統合した感情モデルを設計し、Unity と Python (FastAPI + PyTorch) を WebSocket でリアルタイム接続。 GRU による時系列記憶と VAE による動作の個体差表現まで設計しています。

ROBOcustom

ゲーム開発 ／ Unity + C#

ロボットカスタマイズ × ビジュアルプログラミングのバトルゲーム。 自作ノードエディタでロボットの行動ロジックを組み、AI同士のバトルで撃破数を競います。 ゲームAI・物理判定・アイテムシステムを実装。

HuMoT 再現実装

論文再現 ／ PyTorch

トポロジー非依存のモーションリターゲティング Transformer (arXiv:2305.18897) を、 公式コード非公開の中 PyTorch でフルスクラッチ再現。XCiT ブロックから学習ループ、 テスト一式まで約216万パラメータのモデルを実装しました。

MoST (CVPR 2024) の Windows 移植

学習環境構築 ／ PyTorch + CUDA

モーションスタイル変換モデル MoST を Linux 前提の公式環境から Windows + RTX 4060 Ti へ移植。CUDA 非互換の解決、コードパッチ、 データ前処理から GPU 学習の検証まで完了しました。

TripoSplat ローカル運用

3D生成 ／ 3D Gaussian Splatting

1枚の画像から 3D Gaussian Splat（最大26万個）を生成するモデルを ローカルGPUにセットアップし、画像→3D生成パイプラインを構築・運用しています。
